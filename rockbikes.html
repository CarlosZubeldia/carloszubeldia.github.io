About the projectSobre el proyecto

Rock Bikes is my first project built with AI: the home page and product page of a mountain bike e-commerce site, taken from Figma to code.

The design comes from an agency project for an electric scooter shop. To be able to show it, I anonymised it: new name, new brand and mountain bikes instead of scooters.

The code was written by AI. My work was to design, set the rules, review every change and decide when something was finished.

Rock Bikes es mi primer proyecto construido con IA: la home y la ficha de producto de un e-commerce de bicicletas de montaña, llevadas de Figma a código.

El diseño parte de un proyecto de agencia para una tienda de patinetes eléctricos. Para poder enseñarlo lo anonimicé: nuevo nombre, nueva marca y bicis de montaña en lugar de patinetes.

El código lo escribió la IA. Mi trabajo fue diseñar, fijar las reglas, revisar cada cambio y decidir cuándo algo estaba terminado.

ChallengeEl reto

Turn a high-fidelity Figma design into a website that looks identical to the design and whose interactions feel like a real shop: menus, search, carousels, video and a product page.Convertir un diseño de Figma de alta fidelidad en una web idéntica al diseño y con interacciones que se sientan como las de una tienda real: menús, buscador, carruseles, vídeo y ficha de producto.

The added difficulty: I'm a designer, not a developer. I needed a way of working with AI where I kept control over the result.La dificultad añadida: soy diseñador, no programador. Necesitaba una forma de trabajar con la IA en la que yo mantuviera el control del resultado.

ScopeAlcance

A complete home page with 11 sections and a product page, both adapted to mobile. The rest of the links are placeholders: the goal was to show the process, not to launch a shop.Una home completa con 11 secciones y una ficha de producto, ambas adaptadas a móvil. El resto de enlaces son provisionales: el objetivo era mostrar el proceso, no lanzar una tienda.

A static website with no frameworks or build step: plain HTML, CSS and JavaScript that anyone can open and maintain.Una web estática sin frameworks ni compilación: HTML, CSS y JavaScript que cualquiera puede abrir y mantener.

How I worked with AICómo trabajé con la IA

AI writes code fast, but it doesn't know when the result is right. I organised the project so that every decision was mine and every change could be checked.La IA escribe código rápido, pero no sabe cuándo el resultado está bien. Organicé el proyecto para que cada decisión fuera mía y cada cambio se pudiera comprobar.

01. Figma as the source of truthFigma como fuente de verdad

Cursor read the design directly from Figma through its API: frames, colours, type sizes and images. Each section was built from its frame and compared against its render.Cursor leía el diseño directamente de Figma a través de su API: frames, colores, tamaños de texto e imágenes. Cada sección se construyó a partir de su frame y se comparó con su render.

02. Project rulesReglas del proyecto

I wrote rules the AI follows in every conversation: style guide, mobile layout, WCAG 2.2 AA accessibility and how to work with me (small changes, plain-language explanations, ask before big changes).Escribí reglas que la IA sigue en cada conversación: guía de estilos, maquetación móvil, accesibilidad WCAG 2.2 AA y cómo trabajar conmigo (cambios pequeños, explicaciones sin jerga, preguntar antes de cambios grandes).

03. Measure, don't eyeballMedir, no mirar a ojo

Nothing was accepted without proof. Each change ended with a real browser screenshot or a measurement, compared with the Figma frame. The product page differs from its design by 1.89% of pixels.Nada se daba por bueno sin una prueba. Cada cambio terminaba con una captura real del navegador o una medida, comparada con el frame de Figma. La ficha de producto difiere de su diseño en un 1,89 % de los píxeles.

04. Versions and memoryVersiones y memoria

I created my own commands to review a page and save a version. Each structural change was documented in a decision log, so any AI or person can pick up the project without losing context.Creé mis propios comandos para revisar una página y guardar una versión. Cada cambio estructural se documentó en una bitácora de decisiones, para que cualquier IA o persona pueda retomar el proyecto sin perder el contexto.

Key design decisionsDecisiones clave de diseño

A system, not pagesUn sistema, no páginas

Tokens for every repeated colour and measurement, one button family with shared states and one rule for headings: new sections fit in without breaking the whole.Tokens para cada color y medida repetidos, una sola familia de botones con estados compartidos y una regla para los titulares: las secciones nuevas encajan sin romper el conjunto.

Contrast over videoContraste sobre vídeo

A dark layer over the hero video keeps the text readable on every frame. Card numbers that blended into light photos were switched to pure white.Una capa oscura sobre el vídeo del hero mantiene el texto legible en cualquier fotograma. Los números de tarjeta que se perdían sobre fotos claras pasaron a blanco puro.

Usable without a mouseUsable sin ratón

Visible focus on every control, hover interactions that also work with the keyboard, and hidden elements kept out of the tab order.Foco visible en todos los controles, interacciones de hover que también funcionan con teclado y elementos ocultos fuera del orden de tabulación.

ReflectionsReflexiones

AI didn't replace design work: it moved it. Less time drawing, more time defining rules, reviewing and deciding. The clearer the design system and the criteria, the better the code the AI produced.La IA no sustituyó el trabajo de diseño: lo desplazó. Menos tiempo dibujando y más tiempo definiendo reglas, revisando y decidiendo. Cuanto más claros eran el sistema de diseño y los criterios, mejor era el código que producía la IA.

This project shows I can take a design all the way to a working product and work with developers using the same language.Este proyecto demuestra que puedo llevar un diseño hasta un producto que funciona y trabajar con desarrollo hablando el mismo idioma.
